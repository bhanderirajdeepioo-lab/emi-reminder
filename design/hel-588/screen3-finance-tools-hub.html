Finance Tools Hub — Spec Notes (HEL-588 × s19)

Aligned with existing wireframe at design/emi-app/wireframes/19-finance-tools-hub.svg. Adds Search state (Frame 2) and updates to match HEL-588 brand tokens.

Top App Bar

  • Background: Indigo600 → Violet600 linear gradient (135°) — matches existing s19 SVG
  • Back button: 36×36dp circle, rgba(white,0.1) bg
  • Title: 18sp Bold white, flex:1 centred
  • Search icon: 36dp touch target

Search Bar

  • White card, 12dp radius, 1px Slate200 border (idle), 1.5px Indigo600 border (active)
  • Padding: 10×14dp; font: 14sp Slate400 placeholder
  • Active: clears on ✕ tap, result list replaces full section layout

Loan Calculators (Vertical List)

  • Row anatomy: 40×40dp icon bubble (12dp radius, category-tint bg) + tool name 14sp SemiBold + desc 12sp Slate400 + chevron › Slate200
  • Row height: 56dp minimum, 8dp gap between rows
  • Step-up EMI + Balance Transfer: NEW badge (9sp Bold uppercase, Indigo600 bg, white text, 6dp radius)
  • Icon tints: EMI=Indigo50, Comparison=Violet50, Prepayment=Green50, Step-up=Orange50, BalTrans=Pink50

Investment Tools Grid (2×2)

  • Grid: 2 cols, 10dp gap, 16dp horizontal margin
  • Card: 16dp radius, white, 1dp shadow; decorative tint blob top-right (category colour, 8% opacity)
  • Card content: 40dp icon bubble + tool name 13sp Bold + desc 11sp Slate400
  • SIP=Teal, FD/RD=Amber, PPF=SafeGreen, GST=Blue

"4 More" Strip

  • White card, horizontal scroll, no scrollbar, 4 tools visible (no overflow cue)
  • Each tool: 48×48dp icon (14dp radius) + label 10sp Slate600 below
  • Coming-soon badge: 16dp Amber700 circle, ! white, top-right absolute, 2dp white border
  • Tapping a coming-soon tool → bottom sheet: "Coming in Q3 2026 — tap to get notified"

Navigation

  • Reachable from: Finance Tab via "Tools" entry in the tab bar / header action
  • Back button → Finance Tab (SmsDashboard, Screen 1)
  • Each tool row / card tap → opens that calculator screen (s20–s28)

Consistency with HEL-588 Smart Card + Detail Screens

  • Same Indigo600 primary, same Slate200 borders, same 8dp-grid spacing
  • Same bottom nav (Finance tab active)
  • Gradient AppBar matches s19 existing SVG — no change to established brand
  • Row shadows: 0 1px 3px rgba(0,0,0,0.07) — lighter than Finance Tab txn cards to de-emphasise tool rows vs. transaction data
