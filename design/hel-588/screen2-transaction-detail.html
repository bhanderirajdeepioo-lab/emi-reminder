Screen 2 — Design Annotations

Transaction Detail Screen — Spec Notes

TopAppBar

  • Primary Indigo600 background, matching Finance Tab
  • Back button: 40×40dp circular, rgba(white,0.1) bg
  • Title: 18sp SemiBold white, centred flex
  • Share icon: system Share icon, 40dp touch target

Hero Section

  • Background: solid category colour (not Indigo for non-EMI transactions)
  • Icon bubble: 64×64dp, 20dp radius, rgba(white,0.15) fill, rgba(white,0.3) 2dp border
  • Category label: 12sp Bold, uppercase, rgba(white,0.7)
  • Amount: 36sp ExtraBold, white, letter-spacing -1dp
  • Date: 13sp, rgba(white,0.6)
  • EMI pill: rgba(white,0.2) bg, rgba(white,0.4) 1dp border
  • Verified pill: SafeGreen 30% bg, #4ADE80 text
  • Bottom: concave ellipse clip creates soft transition into content bg

Details Card

  • White card, 16dp radius, 1dp Slate100 dividers between rows
  • Label column: 110dp fixed, 13sp Slate400
  • Value column: 13sp Medium Slate800, flex:1
  • Re-assign chip: Indigo50 bg, Indigo600 text, tapping opens category bottom sheet
  • UTR Ref value: monospace 12sp to distinguish from other fields
  • Confidence bar: 4dp tall, SafeGreen gradient; label below shows % + tier (Low/Medium/High/Very High)

Original SMS (Expandable)

  • Collapsed by default — hides noisy raw data until needed (Progressive Disclosure)
  • Chevron rotates 180° on expand (purposeful animation, ~200ms ease-out)
  • SMS text: monospace 12sp, Slate100 bg, 12dp padding, word-break

Notes Section

  • Tap anywhere in field → open inline edit (single-line text)
  • Placeholder: 13sp italic Slate400
  • Filled: 13sp Slate700

Sticky Bottom Bar

  • Always visible, above system nav
  • Mark Verified toggle: Material Switch — ON = SafeGreen, OFF = Slate300
  • Toggle label: 13sp Medium + sub-label (11sp SemiBold green when on)
  • Edit button: Indigo600 bg, white, 14sp SemiBold, 12dp radius, opens Transaction Edit Sheet (HEL-571)
  • Shadow: 0 -4px 20px rgba(0,0,0,0.08)

Interaction Notes

  • Back button → pop to Finance Tab at same scroll position
  • Share → system share sheet with summary text
  • Re-assign chip → bottom sheet with category grid (14 options)
  • Verified toggle → optimistic UI: instant state change + background API call
  • Edit button → opens Transaction Edit Sheet (HEL-571, already in codebase)

Not Found Fallback

  • Red-tinted 80dp icon container
  • Two CTAs: primary (Back to Finance) + text (Retry)
  • Triggered when: deep-link to deleted txn, stale ID from push notification
