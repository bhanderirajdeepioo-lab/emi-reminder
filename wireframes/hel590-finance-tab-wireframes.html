Design notes — Screen 1

A1Smart Summary Card — Slate800 bg (#1E293B), 16dp radius, 20dp padding. Progress bar uses SafeGreen (#059669). "43% saved" label in #34D399 (lighter green for contrast on dark). Uses Chunking (Cognition lens) to separate total vs income vs budget at a glance.
A2Category Filter Chip Bar — 32dp height chips, 8sp gap, scrollable horizontal. Selected chip: Indigo100 bg + Indigo600 border + text. Colour dot (8dp) uses exact CategoryMeta colours — no new tokens needed. Hick's Law: "All" default avoids choice paralysis on load.
A3Transaction Smart Card — 3dp left accent border (category colour), 40dp icon bubble (10% opacity category colour bg), merchant bold 14sp, subtitle 11sp gray. Verified badge: SafeGreen text on #D1FAE5. EMI pill: Indigo600 on Indigo100. Serial Position: verified/EMI badges read left-to-right below title.
A4Filter summary strip — "12 transactions · ₹28,450 total" sits between chip bar and list. Updates reactively on chip selection (Doherty Threshold: sub-400ms update expected).
A5Date group headers — 11sp uppercase gray label, 8dp top padding. "Today", "Yesterday", then "DD Mon" format. Recognition over Recall: relative dates reduce cognitive load for recent items.

Design notes — Screen 2

B1Hero section — Indigo50 (#EEF2FF) bg. 64dp icon bubble (category colour at 15% opacity bg). Amount: 32sp bold, UrgentRed (#DC2626) for debit, SafeGreen for credit. Sub-category shown as a pill below date. Progressive Disclosure: key info at top, details scrollable below.
B2Details card — Single info-card with 1dp separator rows. Label column: 80dp fixed, 11sp Gray500. Value column: 13sp Medium. "Re-assign" chip (Indigo600 border, 10sp) triggers category edit sheet. Confidence indicator: 5 filled/empty dots using Indigo600 / Gray200.
B3Original SMS — Collapsed by default (chevron ▸). Tap reveals raw SMS text in monospace 12sp gray. Progressive Disclosure: power-users can audit, casual users aren't distracted.
B4Bottom action bar — 80dp fixed, splits "Mark Verified" toggle (left, full-width flex) from "Edit Transaction" CTA (right, Indigo600 pill). Toggle ON state: SafeGreen track. Forgiveness principle: toggle is reversible; Edit opens sheet, not destructive.
B5Accessibility — All interactive targets ≥48×48dp. Amount colour is not the sole indicator (label "Debit"/"Credit" + ± sign both present). WCAG 4.5:1 met for all text on white card backgrounds.

Design notes — Screen 3

C1Selected chip colour — When a non-default filter is active the chip adopts the category colour (Health = UrgentRed: #FEE2E2 bg, #DC2626 border + text). This gives instant confirmation of which filter is active without requiring a separate "active" state indicator.
C2Filter summary strip — Switches to UrgentRed text: "0 Health transactions this month". Zero count communicates the empty state before the user even scrolls. Von Restorff effect: red count stands out against normal strip.
C3Empty state placement — Inline below the chip bar (not a fullscreen takeover). Summary card remains visible so context (total spend, budget) is preserved. Goal-Gradient: user sees they have money, just not in this category — less frustrating than a full blank screen.
C4"Clear filter" CTA — Indigo600 outlined pill button (not filled). Secondary visual weight — the primary action here is switching chip, not clearing. Forgiveness principle: one tap returns to All state with no data loss.
C5Summary card unchanged — Smart Summary Card always shows totals across ALL transactions regardless of chip filter, so users maintain a consistent mental model of their overall spending (Jakob's Law + Mental Models lens).
